# Generated deck outputs

Deck Builder saves PDF exports here using `replit-example-deck-v01.pdf`,
`replit-example-deck-v02.pdf`, and so on. Each save scans the existing filenames
and chooses the highest version plus one. Older files are never overwritten.

The app's **Download PDF** action also archives the output here so downloads
and project saves share one version history. The native browser **Print** dialog
is separate: the browser controls its filename, destination, and completion.

Generated PDFs are excluded from Git and publishing bundles. Download important
outputs to your computer for an independent copy. This directory is a project
workspace output location, not shared cloud storage for a published app.
